# Reference imagery

Drop Hay Day screenshots, map captures and video frames in this folder.

**Nothing is here yet.** Phase 3 (farm blockout) is where these start to
matter -- until then the spatial layout has nothing authoritative to follow.

## What is most useful, in priority order

1. **A wide shot of the whole farm.** One image showing the overall layout is
   worth more than ten close-ups. It fixes where the farmhouse, barn, fields
   and animal pens sit relative to each other.
2. **Path shapes.** Where dirt paths run, how wide they are, where they fork.
3. **The farmhouse and barn** from a couple of angles, for proportions.
4. **Animal areas** -- chicken coop, cow pasture, sheep pen -- with their fences.
5. **The pond / water feature** and its surroundings.
6. **Any sunset or evening shot.** The sunset preset is called out in the
   brief as especially important, and colour references are hard to guess.

## Naming

Free-form is fine, but a prefix helps: `farm_overview_01.png`,
`house_front.png`, `path_fork.png`, `sunset_01.png`.

## Note on sourcing

These are for reproducing layout and atmosphere by hand. Do not add assets
extracted from the game's own files -- the project reconstructs the
environment with original and legally obtained assets instead.

## Git LFS

`.gitattributes` routes images through Git LFS. Run `git lfs install` once on
your machine before adding any, or they will be committed as raw blobs.
